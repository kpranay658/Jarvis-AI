# Jarvis AI 🤖

A personal AI assistant designed to streamline daily tasks, automate workflows, and provide intelligent assistance through voice and text.

## Features ✨
* **Voice Interaction:** Speech-to-text and text-to-speech capabilities.
* **Task Automation:** Execute system commands and browser automation.
* **Intelligent Responses:** Powered by advanced LLMs (e.g., OpenAI/Gemini).
* **Modular Design:** Easily extensible with new plugins and skills.

## Tech Stack 🛠️
* **Language:** Python 3.x
* **Core Libraries:** SpeechRecognition, pyttsx3, openai, langchain, llamaindex, ollama, 
* **Environment:** Virtualenv
